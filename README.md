Repo with maps for GSI Meet and Greet Universe 2025

Subject:
GitHub Universe: Day 1 GitHub GSI and Enterprise Sales Team Meet & Greet Event - 10/28 at 3PM Pacific

Date, Time:
Tuesday, Oct 28 3:00 - 3:45PM Pacific

Location:
Picnic tables/benches near the Gateway Pavilion; between the Stage and Building C. Look for the signage!

Join us for a fast-paced networking session designed to drive connections across GitHub GSI Partners and the GitHub Enterprise Sales team.
